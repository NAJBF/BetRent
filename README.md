# BetRent — Rental Marketplace (Django Implementation)

**BetRent** is a Jiji Ethiopia-style online rental marketplace built with Django and DRF.

## 🚀 Quick Start
- **Admin Email**: `admin@betrent.com`
- **Admin Password**: `admin1234`
- **API Docs**: [http://localhost:8000/api/docs/](http://localhost:8000/api/docs/)

## 🛠️ Build & Deploy (Render)
- **Build Command**: `./build.sh`
- **Start Command**: `uv run gunicorn BetRent.wsgi:application`
